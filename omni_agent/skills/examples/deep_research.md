# Deep Research Skill

When researching:

1. **Start with memory** - memory_search for existing knowledge
2. **Web search** - Use web_search with specific queries, try 2-3 variations
3. **Fetch sources** - web_fetch top 3-5 results
4. **Cross-verify** - Check multiple sources
5. **Synthesize** - Combine into coherent report with citations
6. **Store** - memory_write key findings

Template:
- Query 1: broad overview
- Query 2: specific technical details
- Query 3: recent developments (2025-2026)

Always include:
- Summary
- Key findings (bullet points)
- Sources
- Limitations / gaps
